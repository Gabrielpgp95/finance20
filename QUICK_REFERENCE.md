## Keyboard Shortcuts

Press these keys ANYWHERE in the app:

| Key | Action |
|-----|--------|
| **N** | New Appointment (Programare Nouă) |
| **C** | New Client (Client Nou) |
| **F** | New Invoice (Factură Nouă) |
| **S** | Activate Search (Căutare Globală) |
| **D** | Go to Dashboard |
| **P** | Go to Appointments (Programări) |
| **K** | Go to Calendar |

## Quick Actions Reference

### From Dashboard:
- Click "⚙️ Vezi Toate Funcțiile în Setări" button → Opens Settings

### From Settings Quick Actions:
- ⏰ Smart Reminders → Opens reminders for all upcoming appointments
- 🔍 Căutare Globală → Activates search box and focuses it
- 🌙 Toggle Dark Mode → Switches between light/dark instantly
- 📊 Grafic Venituri → Opens/closes 6-month revenue chart
- 📄 Raport PDF Complet → Downloads full business report
- 💾 Backup Manual → Creates immediate backup

## Feature Locations

### 🏷️ Client Tags (VIP, Recurring, New)
**Where**: Client Form → When adding/editing any client
**Path**: Clienți Tab → Click any client OR ➕ Adaugă Client
**What**: Checkboxes for ⭐ VIP, 🔄 Recurent, ✨ Nou

### 🔔 Appointment Reminders
**Where**: Appointment Form → When creating new appointment
**Path**: Programări Tab → ➕ Programează
**What**: Dropdown "⏰ Reminder Automat" with 1, 3, 7 days options

### 📥 CSV Import
**Where**: Clients section header
**Path**: Clienți Tab → Top right → 📥 Import CSV button
**OR**: Settings → Import CSV Clienți → 📂 Import CSV Acum button

### 📊 Revenue Chart
**Where**: Dashboard OR Settings
**Path 1**: Dashboard → Scroll down → Click "📊 Grafic Venituri"
**Path 2**: Settings → Quick Actions → Click "📊 Grafic Venituri"

### 💰 Monthly Revenue
**Where**: Dashboard stats
**Path**: Dashboard → Look for green card "Venituri Luna Aceasta"
**Note**: Now FIXED and syncs correctly with invoices!

### 📄 PDF Exports
**Where**: Dashboard export section OR Settings
**Path 1**: Dashboard → Scroll to "📥 Export Rapoarte"
**Path 2**: Settings → Quick Actions → "📄 Raport PDF Complet"
**Available**:
- 📄 PDF Programări
- 📄 PDF Venituri  
- 📄 PDF Clienți
- 📊 PDF Raport Complet

### 🔍 Duplicate Detection
**Where**: Automatic when adding new client
**Path**: Clienți → ➕ Adaugă Client → Type name → Auto-checks
**What**: If name is >70% similar to existing, you get warning

### 🎨 Service Colors
**Where**: Calendar views
**Path**: Calendar Tab → Switch to Săptămână or Zi view
**What**: Each service type has unique gradient color

### 🔄 Sync Controls
**Where**: Top of page (collapsible)
**Path**: Any page → Click "🔄 Sincronizare" to expand
**Actions**:
- ⬆️ Trimite (Push to server)
- ⬇️ Preia (Pull from server)
- 💾 Backup-uri (View/restore backups)

## Most Common Tasks

### I want to: Add a new client with VIP tag
1. Press **C** key OR click "➕ Client Nou"
2. Fill in name, phone, email
3. Check ✅ ⭐ VIP checkbox
4. Click "Salvează Client"

### I want to: See monthly revenue
1. Press **D** key to go to Dashboard
2. Look at green card "Venituri Luna Aceasta"
3. Shows total from all paid invoices this month

### I want to: Export all data to PDF
1. Go to Settings (⚙️ tab)
2. Click "📄 Raport PDF Complet" in Quick Actions
3. PDF downloads automatically

### I want to: Send appointment reminder
1. Press **S** to activate search
2. Type client name
3. Click appointment in results
4. Click "📱 Trimite SMS Reminder" or Telegram option

### I want to: Toggle dark mode
1. Press **D** twice (go to dashboard) then click toggle
   OR
2. Settings → Quick Actions → "🌙 Toggle Dark Mode"
   OR
3. Top header → Click "🌙 Mod Întunecat" checkbox

### I want to: Create manual backup
1. Settings → Quick Actions → "💾 Backup Manual"
   OR
2. Click "🔄 Sincronizare" → "💾 Backup-uri"

### I want to: View top clients
1. Press **D** to go to Dashboard
2. Scroll to "🏆 Top 5 Clienți" section
3. See ranked list with revenue totals

### I want to: Import clients from CSV
1. Clienți Tab → "📥 Import CSV" button
   OR
2. Settings → Import CSV section → "📂 Import CSV Acum"
3. Select CSV file (format: nume,telefon,email)

## Troubleshooting

**Problem**: Can't find Quick Actions Panel  
**Solution**: Go to Settings (⚙️) tab, scroll to top

**Problem**: Revenue shows 0  
**Solution**: Make sure invoices are marked "paid" with dates

**Problem**: Welcome screen won't show again  
**Solution**: Open browser console → Type: `localStorage.setItem('featureVersion', '0.0')` → Reload

**Problem**: Keyboard shortcuts don't work  
**Solution**: Make sure you're not typing in an input field

**Problem**: Smart Features Status not visible  
**Solution**: Go to Dashboard → Click "📊 Panou de Control" to expand
